Google Apps Script

Le projet contient déjà un script prêt pour les commandes.

  1. Ouvrez votre Google Sheet.
  2. Extensions → Apps Script.
  3. Copiez apps-script/Code.gs du ZIP.
  4. Déployez → Nouveau déploiement → Application Web.
  5. Exécuter en tant que vous-même et autoriser l’accès selon votre besoin.
  6. Copiez l’URL /exec dans le champ Google Sheets ci-dessus.

Les paramètres Supabase et les accès administrateur restent gérés depuis votre projet Supabase.
